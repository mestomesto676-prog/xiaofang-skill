# “生活大于考研”字体、字号与行距规范

本规范以抖音竖屏 `1080 × 1920` 为基准。横屏或其他尺寸按画布宽度等比缩放，再通过真实渲染帧微调。

## 1. 字体体系

A–C、E–H 只保留两种频道字体：

| 功能 | 字体 | 用途 |
|---|---|---|
| 观点字体 | 得意黑（Smiley Sans） | 一级观点、二级逻辑、短结论、栏目标题 |
| 阅读字体 | 苹方（PingFang SC） | 三级注释、正文、字幕、数字单位、标签 |

不得为了“丰富”临时加入其他字体。需要书卷感、紧迫感或温度时，优先通过字号、字重、留白、框线和素材表达。

D｜像素纸刊编辑风是明确例外：一级、二级标题使用宋体、仿宋、旧铅字或老报纸标题方向；英文小标题使用 Bodoni、Didot、Cormorant Garamond 一类高反差 Serif，可使用 Italic；三级正文和字幕仍使用苹方保证手机端阅读。D 同一项目内最多使用“一套中文印刷标题 + 一套英文 Serif + 苹方正文/字幕”，不得继续增加装饰字体。

## 2. 固定字号基准

| 层级 | 默认字号 | 字体 | 默认行高 | 功能 |
|---|---:|---|---:|---|
| 一级观点 | `132px` | 得意黑；D 为中文印刷标题字 | 单行 `1.05`；多行 `1.15` | 每屏唯一核心观点，约 4—10 字 |
| 二级逻辑 | `76px` | 得意黑；D 为中文印刷标题字 | 单行 `1.10`；多行 `1.25` | 解释观点、因果、步骤标题 |
| 三级注释 | `36px` | 苹方 | `1.50` | 数据、标签、单位、辅助说明 |
| 普通字幕 | `46px` | 苹方 | `1.45` | 一句一意，通常不超过两行 |

字号关系固定为：`132 → 76 → 36`。字幕是独立阅读层，不参与标题层级竞争。

## 3. 行距制定逻辑

行高使用无单位倍数，实际基线距离约等于 `font-size × line-height`。

- 大标题要紧凑，但不能让上下两行的字面框相碰。一级观点默认 `1.15`，即 `132px × 1.15 ≈ 152px` 的基线距离；D 的实际印刷字体字面框不同，必须用真实渲染帧复核。
- 二级逻辑承担解释，默认多行 `1.25`，比一级观点更松。
- 三级注释需要连续阅读，固定从 `1.50` 起步。
- 字幕需要在移动画面中快速识别，默认 `1.45`；两行字幕不得低于 `1.42`。
- 单行文字仍必须显式写 `lineHeight`，确保组件变成两行时不会回退到浏览器默认值。

## 4. 字号与换行优先级

文字过长时按以下顺序处理：

1. 先删掉不承担信息的字。
2. 再按语义主动换行，每行保持一个短语。
3. 再缩小字号，一级观点最低不低于 `112px`，二级逻辑最低不低于 `64px`。
4. 仍放不下时拆成两屏，不继续压缩行距或横向缩放文字。

禁止使用 `scaleX`、负字距或低于规范的行高强行塞字。

## 5. 文字块之间的垂直间距

行距解决同一文字块内部的阅读；不同文字块之间必须另设间距：

| 相邻对象 | 最小净间距 |
|---|---:|
| 一级观点 → 二级逻辑 | `48px` |
| 二级逻辑 → 三级注释 | `32px` |
| 标题 → 下划线/删除线 | `24px` |
| 下划线/删除线 → 下一文字块 | `32px` |
| 卡片文字 → 卡片上下边缘 | `24px` |
| 两行字幕 → 字幕框上下边缘 | `22px` |

“净间距”从真实可见字面框边缘开始计算，不从 CSS 盒子的理论边缘计算。

## 6. QA 检查

以下场景必须按 `1080 × 1920` 原尺寸检查稳定帧：

- 一级标题出现两行或以上；
- 标题下方紧跟注释、红蓝强调字、下划线或删除线；
- 字幕出现两行；
- 字号因字数发生动态变化；
- 同屏存在两个以上文字层。

检查顺序：字面框是否相碰 → 行间留白是否均匀 → 文字块间距是否独立 → 是否进入顶部、右侧或底部 UI 安全区。

禁止只看代码中的 `top`、`height` 和 `lineHeight` 判断通过；必须看真实渲染帧。
