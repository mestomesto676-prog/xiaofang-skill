# 纸雕混合制作管线

## 分工

- 生图或静态素材：环境、道具、纸张层次、复杂光影、一次性视觉隐喻。
- 小方骨架或分层素材：所有叙事关键动作。
- Remotion/Canvas/SVG：精确文字、数字、图表、流程、遮罩和时间同步。

## 制作顺序

1. 先写镜头的信息任务和唯一主动作。
2. 生成或制作无文字纸雕场景，预留标题、安全区和小方动作空间。
3. 小方不随底图一起定死；优先单独制作透明分层角色或用参数化骨架。
4. 为动作定义 `stateA`、接触帧、`stateB` 和落定帧。
5. 用代码将小方、道具、文字和底图组合。
6. 分别检查静帧、运动中间态和缩略图。

## 小方分层建议

```text
xiaofang/
├── head
├── eyes
├── torso
├── arm-left-upper / arm-left-lower / hand-left
├── arm-right-upper / arm-right-lower / hand-right
├── leg-left / leg-right
└── shadow
```

纸雕零件保持相同纸纹、边厚和光向。旋转中心放在肩、肘、腕和髋部，不放在图片几何中心。

## 生图约束

- 每次使用角色参考图；不得生成第二个小方版本。
- 不生成标题、数字、图表或必须准确阅读的文字。
- 不为每句话单独生图；同一纸雕空间应由动作和镜头延续。
- 图片只解决静态复杂度，不把整段时间逻辑交给不可控的视频生成。

## 验收

- 小方头身比例、眼睛、轮廓线宽与设定一致。
- 手真正握住、推到或拉住道具。
- 背景没有比主信息更抢眼。
- 文字在原始分辨率下无碰撞，缩略图仍有唯一视觉中心。
- 生图缺陷没有被带入动画后放大。
