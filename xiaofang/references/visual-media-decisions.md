# 视觉媒介决策：文字、动画、生图与代码动画

在写分镜和代码前先做媒介判断。核心只有两句：

- **文字负责说准确，动画负责让关系发生。**
- **静态复杂度交给图片，时间复杂度交给代码。**

每个镜头先问：**它是在展示一个名词，还是让一个逻辑真正发生？**

- 展示名词、结论、场景或情绪 → 文字或图片。
- 展示变化、因果、顺序、比较或反馈 → 动画。

## 1. 什么时候用文字

文字只承担必须被准确记住、复述或复制的信息：

- 核心结论、关键词、术语。
- 数字、条件、公式、对照标签。
- 可直接复制的 AI 提示词。
- 章节导航和必要的动作指令。

约束：

- 字幕承载完整口播；屏幕文字只保留每段 **1 个关键词或 1 句结论**。
- 一屏同时不超过 2 处文字，并继续遵守整片屏幕字约 20 字的风格锁。
- 如果删掉一段屏幕文字，观众仍能看懂，就删掉。
- 不要把完整字幕原样再放进画面。

## 2. 什么时候用动画

动画用来表现静态画面说不清的关系：

- 状态改变：混乱变清晰、错误变正确、计划变行动。
- 先后顺序：先输入，再判断，最后输出。
- 因果关系：做了 A，因此 B 发生变化。
- 数量、速度、距离、进度的比较。
- 小方的动作、表情和停顿所表达的心理变化。

动画必须让观点真正发生。不要用“出现一个图标＋小方站着指”代替表达；如果运动去掉后信息完全不受影响，这个运动多半只是装饰。

## 3. 什么时候用生成图片

适合图片的是**静态但细节复杂**的内容：

- 氛围、环境、复杂空间和难以代码绘制的道具。
- 一眼就能成立、但不需要逐步变化的视觉隐喻。
- 封面主视觉或一次性的情绪画面。
- 代码绘制成本很高、运动价值又很低的复杂场景。

在小方视频中的额外限制：

- 图片只做背景、道具或静态隐喻；小方本体、关键动作和逻辑变化仍由代码控制。
- 不生成另一个造型的小方，不生成额外人物，不让图片模型生成精确文字、数字、图表或提示词。
- 不为每句话生成一张图；同一画面能被动作延续时，优先延续。
- 本 skill 默认仍不调用生图 API。只有用户明确授权后，才进入生图流程；未授权时使用现有素材、用户提供素材或代码替代。

## 4. 什么时候直接用代码做动画

适合代码的是**需要精确、可编辑、可重复、与时间同步**的内容：

- 曲线、路径、计数器、计时器、进度条。
- 流程图、因果链、分类树、卡片排序与逐项揭示。
- 标准小方动作、表情、相机推拉和卡片转场。
- 数据变化、时间同步、同一机制反复演示。
- 需要以后换文案、数字、节奏或批量生产的画面。

不适合硬用代码的内容：写实校园、人群、自然风景、纹理丰富且不需要变化的场景。它们若确有必要，优先用现有/用户提供图片；获得明确授权后才可生图。

## 5. 混合方案

复杂场景里只有局部需要变化时，使用：

**静态图片打底＋代码控制关键运动。**

例如：静态自习室做背景，代码让计时器变化、小方完成动作、任务卡折叠。不要把整段逻辑交给不可控的视频生成。

## 6. 快速决策表

| 镜头的信息任务 | 首选媒介 |
|---|---|
| 需要准确记住或复制 | 文字 |
| 变化、因果、顺序、比较 | 动画 |
| 情绪、氛围、复杂静态场景 | 图片 |
| 图表、流程、数字、标准动作 | 代码动画 |
| 复杂场景中只有关键局部变化 | 图片打底＋代码动画 |

## 7. 分镜必须填写的字段

每个镜头在语法文件头注释中写清：

| 字段 | 要回答的问题 |
|---|---|
| 信息任务 | 观众这一刻要理解什么？ |
| 媒介 | `text` / `code` / `image` / `hybrid` |
| 画面发生了什么 | 哪个对象发生了哪种可见变化？ |
| 屏幕文字 | 必须准确记住的最少文字是什么？ |
| 蓝色语义 | 本片唯一的蓝色概念是什么？ |

如果“画面发生了什么”只能写成“出现图标”或“小方指向图标”，必须重做视觉隐喻。

## 8. 常见错误

- 把完整字幕复制成屏幕文字。
- 每句话配一个图标或一张生成图。
- 连续重复“小方站着指图标”。
- 使用没有信息意义的弹跳、漂浮和转场。
- 用生成图片制作需要精确的文字、数字和图表。
- 用代码硬画无需时间变化的高细节场景。

## 9. “10 个 AI 提示词”类内容的表达示例

- “解释给孩子听”：复杂公式变成生活物件，再重新组成专业表达。
- “判断录取传闻”：混乱信息被分拣为事实、未知、猜测。
- “按评分标准批改”：得分点依次亮起，遗漏处留下缺口。
- “制定今日计划”：巨大的计划表折叠成一张当前任务卡。
- “处理焦虑”：焦虑云拆成事实、猜测、最坏情况，再落到 30 分钟行动。
- “苏格拉底提问”：答案保持遮挡，学生回应后才出现下一步。
- “诊断错题”：错题进入诊断树，落到原因和修复动作。
- “识别进步证据”：学习时长不变，正确率、速度和错误类型发生变化。
