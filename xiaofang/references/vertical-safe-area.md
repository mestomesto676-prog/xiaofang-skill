# 抖音竖屏安全区

## 固定原则

**`9:16` 是最终画布，`2:3` 是不可见的核心构图舞台。**

背景铺满 `9:16`，内容按照 `2:3` 构图；上方留气口，右侧让按钮，底部让文案，核心信息集中在中部偏左。

`2:3` 不是裁切尺寸，不能真的在成片中绘制边框。最终导出始终保持 `1080×1920`。

## 1080×1920 默认边界

| 区域 | 默认值 | 规则 |
|---|---:|---|
| 顶部安全区 | `160px`，允许 `120–180px` | 不放核心标题、关键数字、人物面部 |
| 底部安全区 | `360px`，允许 `300–400px` | 不放任何必须阅读的信息，包括字幕和 CTA |
| 右侧 UI 区 | `180px`，允许 `150–200px` | 不放关键词、人物面部、图表数据、关键 SVG |
| 左侧边距 | `72px`，允许 `60–80px` | 正文、人物和图表不得贴边 |

推荐的不可见核心舞台为：

```ts
export const DOUYIN_SAFE = {
  canvas: {width: 1080, height: 1920},
  top: 160,
  bottom: 360,
  left: 72,
  right: 180,
  coreStage: {x: 72, y: 160, width: 828, height: 1242}, // 精确 2:3
} as const;
```

这是保守默认值。具体平台 UI 有变化时可以扩大留白，但不得把必须阅读的信息推入排除区。

## 内容分级

必须进入核心舞台：

- 一级标题、主题观点和结论。
- 人物面部、关键动作与核心人物轮廓。
- 关键 SVG、图表刻度、数字证据与答案。
- 字幕、黑色重点结论框和关注 CTA。

允许突破核心舞台：

- 背景颜色、纹理和环境轮廓。
- 建筑、书桌、房间等非关键场景延伸。
- 不承担阅读任务的线条、色块和装饰 SVG。
- 被平台 UI 遮挡后仍不影响逻辑的辅助物件。

## Remotion 组件约定

- `FullBleedBackground`：覆盖整个 `1080×1920`，不受核心舞台限制。
- `CoreStage`：承载必须阅读和识别的主要内容，默认使用 `coreStage` 坐标并左偏构图。
- `CaptionSafe`：字幕底边默认不低于 `bottom: 380px`，最大宽度不得进入右侧 `180px` UI 区。
- `SafeAreaOverlay`：只用于 Studio、静帧和接触表 QA；最终 composition 必须关闭。

不要把所有元素机械居中到 `CoreStage`。中部偏左是注意力中心，右侧留给平台按钮，剩余空间用留白和背景关系平衡。

## SVG 素材约定

- `core` 素材：人物、核心物品、关键图表与数字。设计时保证在 `2:3` 舞台内仍能完整识别。
- `decorative` 素材：环境、纹理、辅助线条与非关键信息，可延伸到完整 `9:16`。
- 素材文件不保存安全区框；通过索引字段 `safeClass` 和 `preferredZone` 标注用途。

## QA

每条竖屏视频至少检查：Hook 首帧、Hook 冲突帧、主题亮题、一个正文复杂场景、结论和关注页。

检查问题：

1. 顶部 `160px` 是否出现核心标题或数字？
2. 右侧 `180px` 是否压住人物面部、关键词或数据？
3. 底部 `360px` 是否存在字幕、CTA 或必须阅读的信息？
4. 去掉 `2:3` 遮罩后，画面是否仍自然，而不是像被塞进一个 PPT 框？
5. 突破核心舞台的元素是否全部属于背景或非关键信息？

通过安全区检查后必须关闭 `SafeAreaOverlay`，再渲染最终成片。
