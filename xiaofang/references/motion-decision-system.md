# 运动决策与审查系统

本系统负责把动画审美转成可执行、可审查的制片判断。它不替代信息动画十二原则：本文件先决定“该不该动、为什么动、如何验收”，十二原则再决定“怎样动得清楚、自然、有吸引力”。

总原则：

```text
静态可读 → 运动有因 → 信息有序 → 快速落定 → 独立审查
```

## 一、运动机会筛选

不要把“每个镜头都做动画”当成完成度。对每个镜头先检查：

1. 静止状态能否看懂唯一视觉中心与结论？不能则先修构图。
2. 删除动作后，观点、关系、状态、方向或情绪是否有损失？没有则删除。
3. 动作是否引入新信息，而不是复述旁白或掩盖内容空洞？
4. 动作是否会抢占文字阅读、数字判断或证据观察的时间？会则缩短、延后或删除。
5. 是否存在更简单的表达：硬切、对象延续、局部高亮或静态对比？优先选能完整表达逻辑的最轻方案。

不设动画数量配额。短名单只保留高确信度机会；没有合格机会也是有效结论。

## 二、准入目的

每个动作必须明确命中至少一个目的：

- `explanation`：演示因果、步骤、机制或数量变化。
- `state-change`：让前后状态差异可见。
- `spatial-continuity`：交代对象来自哪里、去向哪里或镜头之间的对应关系。
- `emphasis`：把注意力交给当前必须看到的词、数字或证据。
- `emotion`：表现人物反应、压力、犹豫、释然等叙事情绪。
- `bridge`：防止必要内容出现、消失或替换时产生难以理解的突变。

“更酷”“更丰富”“避免画面太空”不是合格目的。装饰若不能提高理解、情绪或记忆，应保持静态或删除。

## 三、逐镜决策顺序

严格按顺序做，不要先选缓动或特效：

1. 写出本镜唯一结论和静态替代方案。
2. 定义 `stateA`、`stateB`，必要时增加一个转折姿势。
3. 选择运动目的，写明删除动作会损失什么。
4. 确定唯一主动作；辅助动作只能解释因果、惯性或人物状态。
5. 选择最轻实现：硬切 / 对象延续 / 透明度 / 短位移 / 遮罩 / 路径生长 / 数值变化 / 实体弧线 / 克制 spring。
6. 用旁白重音、词级时间戳或逻辑成立点确定开始、转折、落定和退出帧。
7. 从统一运动 token 选择缓动；没有合适 token 时先说明原因，再新增一次并复用。
8. 检查退出方式是否为下一镜让路，避免所有元素同时离场或无意义清空画布。

## 四、运动 token

运动 token 描述意图，不规定所有镜头使用同一时长。实际帧数以旁白、阅读量、对象重量和信息完成度为准。

| Token | 使用场景 | 行为 |
|---|---|---|
| `enter-fast-settle` | 标题、标签、辅助对象进入 | 立即可见，短距离进入，快速稳定 |
| `move-smooth` | 对象在屏内移动或关系重组 | 连续加减速，路径与因果一致 |
| `reveal-linear` | 进度、倒计时、路径或线条生长 | 匀速只表达真实的连续过程 |
| `emphasis-pulse` | 一次性强调关键词或数字 | 幅度克制，完成后立即稳定 |
| `physical-spring` | 人物、纸张、实体物品的轻微惯性 | 高阻尼、低回弹，不用于正文文字和数据 |
| `exit-quick` | 为下一镜释放空间 | 比进入更简短，不与下一镜争夺注意力 |

不要把 UI 的“低于 300ms”“只用 transform/opacity”“永不使用 ease-in”等规则机械搬到视频。固定视频服从旁白和观看认知；遮罩、路径、逐字和必要的预备动作均可使用，但必须说明信息目的。

## 五、高杠杆原型

只为 Hook、主题观点、核心因果、关键转折或封面主视觉等高价值画面制作多方案。每个方案必须沿一个可命名轴线分叉，例如：

- 信息图解 / 情境叙事
- 物件隐喻 / 人物动作
- 静态证据 / 动态关系演示
- 克制理性 / 情绪张力
- 对象延续 / 直接切换

所有方案共享频道 token 和事实约束，且单独达到可评审质量。换色、换字体或轻微位移不算真正的不同方案。选定后只把胜出方向进入正式工程，其余方案不污染生产结构。

## 六、制作与审查分离

同一个任务依次使用四种姿态，不要混在一次随手调整里：

1. **机会筛选者**：只判断哪里值得动、哪里应该保持静态。
2. **动画制作者**：按已锁定的目的、状态和时间锚点实现，不重新扩张分镜。
3. **单镜审查者**：检查一处动画是否清楚、克制、稳定，不顺手重写其他镜头。
4. **全片审计者**：只读完整成片与交付物，按影响排序提出定向返工，不继续发散新创意。

## 七、单镜审查

依次检查：

1. 目的：为什么动？删除是否更清楚？
2. 顺序：观众先看到的是否正是先要理解的？
3. 主次：是否只有一个主动作和一个视觉中心？
4. 物理与语义：起点、方向、路径、遮挡和落点是否合理？
5. Timing：是否踩中旁白重音，是否在需要阅读时已经稳定？
6. 退出：是否干扰下一镜，或制造无信息空白？
7. 一致性：是否符合本期画风、运动 token 和相邻镜头性格？

发现必须写成：

| 当前表现 | 修改后 | 原因 |
|---|---|---|
| 所有元素同时出现 | 主体先建立，证据随后出现 | 先建立对象，再给出判断依据 |

避免“更有质感”“优化节奏”“加强动效”等无法执行的评价。

## 八、全片运动审计

先完整观看一次再逐镜检查，避免只优化局部。按以下顺序处理：

1. 删除没有目的或重复表达的动画。
2. 减少幅度、属性数量和同时运动的元素。
3. 修正信息出现顺序、起点、方向和落定状态。
4. 修正时间锚点、停留时间和退出方式。
5. 最后才处理缓动、轻微跟随、遮罩、模糊或弹性等质感细节。

优先级：

- `P0`：造成事实错误、字幕/画面冲突、关键内容不可读或无法发布。
- `P1`：明显影响理解、留存、节奏、品牌一致性或运动可信度。
- `P2`：不阻碍理解的局部质感问题。

结论：

- `Block`：存在 P0 或未解决的关键 P1。
- `Revise`：问题范围明确，定向返工后可交付。
- `Approve`：无阻断项，运动目的、信息顺序、阅读时间和整体一致性均成立。
