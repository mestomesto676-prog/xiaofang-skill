# 生活大于考研｜频道旁白配置

## 默认声音

- 用户确认名称：`Credible Alex`
- MiniMax API Voice ID：`English_Trustworth_Man`
- 模型：`speech-2.8-hd`
- 语言增强：`Chinese`
- 默认情绪：`fluent`
- 音调：`0`
- 音量：`1.0`
- 采样率：`44100 Hz`
- 母版码率：`128 kbps`

## 默认速度

1. 先以 `speed=1.0` 生成未变速母版。
2. 从未变速母版执行 `ffmpeg -filter:a atempo=1.23`。
3. 最终试听或旁白码率使用 `192 kbps`，并保持音高不变。
4. 不得在已经变速的文件上再次叠加变速。

## 使用规则

- 这是“生活大于考研”的默认频道声音和速度，未来旁白没有新指示时直接使用。
- “真实感”优先于播音腔：保留自然停顿、句间呼吸和轻微语气变化，不把每句话处理成同一重音。
- 默认直接使用已确认的 `Credible Alex + fluent + 1.23 倍速` 生成全文旁白，不再为每期制作三种情绪强度样片，也不重复确认音色、情绪和速度。
- 只有用户在当前任务明确要求更换声音、语速、情绪方向，或指出旁白情绪/断句存在问题时，才重新制作针对性的试听样片。
- 用户明确要求其他音色、情绪或速度时，以当前任务要求为准，不覆盖本频道默认配置，除非用户明确要求更新默认值。
- API Key 优先从 `MINIMAX_API_KEY` 环境变量读取；macOS 上也可从钥匙串服务 `minimax-api-key`、账户 `codex-remotion` 自动读取。绝不写入配置、脚本、日志或工程。
